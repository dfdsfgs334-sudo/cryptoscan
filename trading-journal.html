API-ключ Binance

Создай ключ в Binance → API Management с правом только чтение (Enable Reading). Ключи с правом вывода не принимаются. Secret шифруется AES-256-GCM и хранится только на сервере.

Синхронизация

—
Первая загрузка = полная: у Binance нет общего списка сделок, поэтому проверяется каждая из ~3000 спотовых пар (с учётом лимитов API это 10–15 минут; вкладку держи открытой — прогресс сохраняется, можно продолжить позже). Дальше «Синхронизировать» проверяет только твои пары и монеты на балансе — секунды.

Фьючерсы USDⓈ-M: Binance отдаёт по API только последние ~6 месяцев. Более старую историю загрузи файлом ниже.

Импорт истории из файла

Binance → Orders → Spot Order / Futures Order → Trade History → Export. Поддерживаются CSV и XLSX. Дубликаты сделок, уже загруженных по API, пропускаются автоматически.

Данные

PnL по споту считается методом средней цены входа. Комиссии в BNB и пары не к доллару пересчитываются в $ по текущему курсу — это приближение. Продажи монет, купленных до начала истории (депозит/конвертация), не учитываются в PnL.
